# Atlas de Leonida

Mapa interactivo de fans de GTA 6 (Leonida y Vice City) en español, con las fuentes de cada lugar. Hecho por [Explicado en 60](https://www.youtube.com/@explicadoen60es).

**Proyecto de fans no oficial.** No está afiliado a Rockstar Games ni a Take-Two Interactive. GTA y los nombres del juego son marcas de sus dueños. El mapa base es un trazado propio y aproximado: no contiene imágenes ni material de Rockstar.

Esta carpeta es la web ya generada. Se construye con `tools/construir_web.py` desde el proyecto del mapa; no se edita a mano.
